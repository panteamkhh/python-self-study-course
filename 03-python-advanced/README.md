A self-study, project-ready **Advanced Python** course. No videos required — every lesson is a complete, hands-on unit you work through at your own pace and push to your own GitHub repo.

## Lesson Structure

Each `Lesson-XX-Topic/` folder contains:

- `lesson.md` — full explanation, diagrams, 3 worked examples, common mistakes, and debugging practice
- `examples.py` — every example from the lesson, ready to run
- `exercise.md` — 10 progressively harder exercises (Easy / Medium / Hard)
- `solution.py` — complete, explained solutions to every exercise
- `quiz.md` — 20 questions (MCQ, True/False, Short Answer) with an answer key

## How to Use This Repo

1. Read `lesson.md` for the lesson.
2. Run `examples.py` to see the concepts in action.
3. Attempt every exercise in `exercise.md` **before** looking at `solution.py`.
4. Take the `quiz.md` to check your understanding.
5. Move to the next `Lesson-XX` folder.

```sh
python3 Lesson-11-Classes-and-Objects/examples.py
python3 Lesson-11-Classes-and-Objects/solution.py
```

## Requirements

- Python 3.8+
- No external libraries needed — everything uses the standard library only.
