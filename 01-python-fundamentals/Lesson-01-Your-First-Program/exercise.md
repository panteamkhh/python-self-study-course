# Lesson 01 — Exercises

## Easy

1. Write a program that prints exactly one line: `I am learning Python.`

2. Write a program that prints your first name on one line and your favorite hobby on the next line, using two separate `print()` calls.

3. Write a program with a comment above it explaining what it does, then have it print: `This program was written by me.`

4. Write a program that prints the following three lines, in order:
   ```
   Step 1: Wake up
   Step 2: Learn Python
   Step 3: Celebrate
   ```

## Medium

5. Write a program that prints a text-only box around a message, similar to:
   ```
   ****************
   * Hello there! *
   ****************
   ```

6. Write a program that prints a sentence containing an apostrophe, for example: `It's a beautiful day to code.` Choose your quote characters carefully so the program runs without error.

7. Write a program that prints a small "receipt" with at least four lines: a store name, two item lines, and a total line.

8. Write a program that deliberately contains two comment lines (using `#`) explaining two different sections of code, and prints two messages, one per section.

## Hard

9. Write a program that prints a 3-line ASCII art shape of your choice (for example, a small triangle made of asterisks), using one `print()` call per line.

10. Write a program that prints a short "terminal session" simulation of at least five lines, showing a fictional command being typed and its fictional output, formatted the way a real terminal would display it (for example, a line starting with `$` followed by a command, then the result on the next lines).
