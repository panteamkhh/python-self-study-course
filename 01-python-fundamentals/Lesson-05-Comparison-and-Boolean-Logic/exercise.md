# Lesson 05 — Exercises

## Easy

1. Create two variables `x = 15` and `y = 9`, then print the result of `x > y`.

2. Create a variable `password = "letmein"` and print the result of comparing it to `"letmein123"` using `==`.

3. Create a variable `temperature = 72` and print whether it is `!=` to `100`.

4. Create a variable `is_logged_in = True` and print the result of `not is_logged_in`.

## Medium

5. Create `age = 16` and print the result of `age >= 18 and age <= 65` (should be `False`).

6. Create `day = "Friday"` and print the result of checking whether it equals `"Saturday"` **or** `"Sunday"`.

7. Create `stock = 0` and `is_preorder = True`, then compute and print whether the item `can_be_purchased` if it should be true when `stock > 0` **or** `is_preorder` is `True`.

8. Create `username = "guest"` and `role = "admin"`, then compute and print `has_full_access`, which should be `True` only if `role == "admin"` **and** `username != "guest"`.

## Hard

9. Create three variables: `has_ticket = True`, `is_vip = False`, `age = 15`. Compute and print `can_enter_vip_lounge`, which should be `True` only if the person `has_ticket` and (`is_vip` or `age >= 21`).

10. Create `balance = 250`, `withdrawal_amount = 300`, and `is_overdraft_allowed = False`. Compute and print `transaction_approved`, which should be `True` if `balance >= withdrawal_amount`, **or** if it's `False` but `is_overdraft_allowed` is `True`. Print the final boolean result.
