# Lesson 04 — Exercises

## Easy

1. Convert the string `"15"` into an integer, add `5` to it, and print the result.

2. Convert the number `42` into a string and print its type using `type()`.

3. Convert the string `"3.75"` into a float, then print the value multiplied by `2`.

4. Create an integer `quantity = 8` and print the sentence `"Quantity: 8"` by converting `quantity` to a string and concatenating it with `+`.

## Medium

5. Given `price_text = "19.99"` and `quantity_text = "3"`, convert both to the correct numeric types and print the total cost.

6. Given a float `temperature = 36.6`, convert it to an `int` and print the result, then explain (as a comment) why the result is not rounded.

7. Given `raw_input = "100"`, convert it to an integer, then build and print the message `"You entered: 100"` using string concatenation.

8. Given `flag_text = "False"`, print what `bool(flag_text)` actually returns, and then write the corrected comparison that produces the intended boolean value.

## Hard

9. Given three text values representing a product from a file: `name_text = "Notebook"`, `price_text = "4.50"`, `qty_text = "20"`, convert the numeric ones to the correct types and print a summary line combining all three using string concatenation, showing the total value of stock (`price * qty`) as part of the message.

10. Given `seconds_text = "5000"`, convert it to an integer and then, using floor division and modulo (from Lesson 03), compute and print the equivalent hours and minutes as a single concatenated string message (e.g. `"1 hours and 23 minutes"`).
