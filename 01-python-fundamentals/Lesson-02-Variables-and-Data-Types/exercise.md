# Lesson 02 — Exercises

## Easy

1. Create a variable called `city` holding your city's name and print it.

2. Create two variables, `first_name` and `last_name`, and print them on the same line using one `print()` call with a comma between them.

3. Create a variable `temperature` set to `98.6` and print both its value and its type using `type()`.

4. Create a variable `is_raining` set to `False`, then print a sentence that includes its value, e.g. `Is it raining? False`.

## Medium

5. Create a variable `price` set to `19.99`, reassign it to `24.99`, and print the value after reassignment.

6. Create four variables describing a book (`title`, `author`, `year`, `in_stock`) with realistic values, then print all four using labeled `print()` statements (e.g. `Title: ...`).

7. Create a variable `count` set to `10` as an integer, then create a second variable `count_text` holding the same number as a string `"10"`. Print the type of each to show they are different.

8. Write a short program with at least three variables that intentionally get reassigned to a different data type partway through, printing the type before and after each reassignment.

## Hard

9. Create a set of variables representing a product in a store (name, price, quantity in stock, whether it's on sale), then print a short multi-line summary using labeled output for each variable.

10. Create variables for a simple "game character" (name, health as an int, attack power as a float, is_alive as a bool). Print a status report using multiple labeled `print()` statements, and include a call to `type()` for at least two of the variables.
