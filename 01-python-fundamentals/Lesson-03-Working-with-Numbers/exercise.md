# Lesson 03 — Exercises

## Easy

1. Create two variables, `x = 12` and `y = 4`, and print the results of adding, subtracting, multiplying, and dividing them (four separate `print()` calls).

2. Create a variable `seconds = 45` and print how many minutes and leftover seconds that represents if there were `90` total seconds instead (use `//` and `%`).

3. Print the result of `2 ** 10`.

4. Create a variable `price = 9.99` and a variable `quantity = 3`, then print the total cost.

## Medium

5. Write a program that converts a temperature reading of `98` given in a raw sensor unit into a percentage of a max possible reading of `120` (i.e., compute `98 / 120 * 100`), rounded to 1 decimal place.

6. A pizza has `8` slices. Given `pizzas = 5` and `people = 12`, calculate how many whole slices each person gets and how many slices are left over, using `//` and `%`.

7. Write a program calculating the area and perimeter of a rectangle with `width = 12.5` and `height = 7.25`, printing both results rounded to 2 decimal places.

8. Given `distance_km = 42.195` (a marathon) and `time_hours = 3.5`, calculate and print the average speed in km/h, rounded to 2 decimal places.

## Hard

9. A store charges `price = 45.00` for an item, applies a `discount_percent = 15` and then an additional `tax_percent = 8` on the discounted price. Calculate and print the final price, rounded to 2 decimals, showing the intermediate discounted price as well.

10. Given `total_seconds = 9045`, calculate and print the equivalent in hours, minutes, and seconds (e.g., `2 hours, 30 minutes, 45 seconds`) using only `//` and `%` operations — no other tools.
