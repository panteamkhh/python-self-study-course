# Lesson 06 — Exercises: Sets and Operations

## Easy

1. Given a list of numbers with duplicates, create a set from it and print how many unique values it contains.
2. Write a program that reads two words and prints `True` if they share at least one common letter, otherwise `False`.
3. Given a set of favorite fruits, write a program that adds a new fruit and removes one, then prints the final set.

## Medium

4. Read two lines of space-separated numbers. Print the numbers that appear in the first line but **not** in the second, sorted in ascending order.
5. Given two sets representing the skills of two job candidates, print the skills unique to each candidate (the symmetric difference), sorted alphabetically.
6. Write a program that checks whether one set of numbers is a **subset** of another, and prints `"yes"` or `"no"`.
7. Given a list of email addresses (some duplicated), print only the unique domains (the part after `@`) found across all addresses.

## Hard

8. Read three lines, each containing space-separated words. Print the words that appear in **all three** lines.
9. Write a program that takes a list of pairs of numbers (as tuples) and removes any pair that is a reverse duplicate — for example, `(1, 2)` and `(2, 1)` should be treated as the same pair, keeping only one.
10. Given a set of user IDs who liked a post and a set of user IDs who commented, print how many users did **only one** of the two actions (not both), without listing their IDs — just the count.
