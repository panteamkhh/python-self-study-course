# Lesson 07 — Exercises: Defining Functions

## Easy

1. Write a function `greet(name)` that returns the string `"Hello, <name>!"`.
2. Write a function `is_even(number)` that returns `True` if a number is even and `False` otherwise.
3. Write a function `add_three(a, b, c)` that returns the sum of three numbers.

## Medium

4. Write a function `is_palindrome(word)` that returns `True` if the word reads the same forwards and backwards (ignore this — just compare directly), otherwise `False`.
5. Write a function `count_vowels(word)` that returns how many vowels (`a, e, i, o, u`) appear in the given word.
6. Write a function `max_of_three(a, b, c)` that returns the largest of three numbers without using the built-in `max()`.
7. Write a function `celsius_to_fahrenheit(celsius)` that converts a Celsius temperature to Fahrenheit and returns it.

## Hard

8. Write a function `is_prime(number)` that returns `True` if the number is prime, otherwise `False`.
9. Write a function `reverse_words(sentence)` that returns a sentence with the order of its words reversed (but each word spelled normally). For example, `"I love Python"` becomes `"Python love I"`.
10. Write a function `factorial(n)` that returns the factorial of `n` using a loop (not recursion), and handle the case `n = 0` correctly (factorial of 0 is 1).
